# browser-bridge（Hermes 插件）

把浏览器当前页面内容桥接给 Hermes AI —— 浏览器扩展 + 本地服务 + 站点适配。

支持站点：**百度贴吧**（API 全量楼层，免滚动）· 小黑盒（开发中）

## 它解决什么问题

你在浏览器（Edge/Chrome）里看贴吧帖子，想直接问 Hermes"这个帖子在说什么"，
但 Hermes 看不到你的浏览器。browser-bridge 解决这个：

1. 你点一下扩展按钮（或以后自动）
2. 扩展把当前页面 URL 推给本地服务
3. 本地服务按站点适配器抓取**完整内容**（贴吧 = 官方 API 全量楼层，不滚动页面）
4. 你在 Hermes 里问"这个帖子讲了什么"，插件工具返回抓到的内容

## 架构

```
┌─────────────┐   POST JSON   ┌──────────────────┐  读取   ┌─────────┐
│ 浏览器扩展    │ ───────────▶ │ Hermes 插件       │ ──────▶ │ Hermes  │
│ extension/  │  URL+标题     │ plugins/browser- │  工具    │  AI     │
└─────────────┘               │ bridge/          │         └─────────┘
                              │  - server.py 本地服务 │
                              │  - tieba_fetch.py 站点适配 │
                              └──────────────────┘
```

- **浏览器扩展**：只负责"我在看哪个页面"，把 URL 交给本地服务
- **Hermes 插件**：内置本地 HTTP 服务（127.0.0.1:4399）+ 站点抓取适配器
  - 贴吧：匿名调用官方接口 `c/f/pb/page`（签名 `tiebaclient!!!`），循环翻页拉全楼层
  - 零滚动、零浏览器依赖（API 直拉）
- **工具**：`page_status`（当前页面元信息）/ `page_content`（读取正文，按块/关键词）/ `page_refresh`（提示重新抓取）

## 安装

### 1. 装 Hermes 插件

```bash
# 把本仓库的插件目录复制到 Hermes 插件目录
cp -r browser-bridge ~/.hermes/plugins/
hermes plugins enable browser-bridge
```

插件启用后自动启动本地服务（127.0.0.1:4399）。

### 2. 装浏览器扩展

1. 打开 `edge://extensions`（或 `chrome://extensions`）
2. 开启"开发人员模式"
3. 点"加载解压缩的扩展"，选择本仓库的 `extension/` 目录
4. 固定到工具栏

### 3. 配置连接（可选）

打开扩展 popup → ⚙️ 连接设置：

- **服务器地址**：默认 `http://127.0.0.1:4399`
- **Token**：从插件目录 `config.json` 里复制（插件首次运行自动生成）

## 使用

1. 在 Edge 打开贴吧帖子
2. 点扩展图标 → 「📥 拉取当前页面」
3. 回 Hermes 问："我刚看的帖子讲了什么"

## 配置项

`config.json`（插件目录，首次运行自动生成，**不要上传到 Git**）：

```json
{ "host": "127.0.0.1", "port": 4399, "token": "<随机生成>" }
```

环境变量可覆盖：`BRIDGE_HOST` / `BRIDGE_PORT` / `BRIDGE_TOKEN`

## 站点适配

| 站点 | 数据源 | 状态 |
|---|---|---|
| 百度贴吧 | 官方 API `c/f/pb/page` + 签名 | ✅ 全量楼层 |
| 小黑盒 | 评论 API（借浏览器 cookie） | 🔨 开发中 |

## 图片处理

每次拉取贴吧帖子时，自动执行：

1. **提取图片 URL**：楼层里的真实图片（非表情）以 `[图片](URL)` 形式保留在正文里
2. **下载到本地**：主楼 + 所有楼层的图片自动下载到插件目录 `state/images/<帖子id>/`
3. **记录路径**：每个楼层的 `images_local` 字段带本地文件路径（`images` 字段带原始 URL），
   供视觉模型后续分析或直接查看

> 表情会转成可读名称（如 `[笑眼]`、`[滑稽]`），不下载。

> 图片只存本地（`state/` 已被 .gitignore 排除），不会上传到 Git。

## 隐私

- 本地服务只监听 127.0.0.1，数据不出本机
- 抓取内容只存本地 `state/` 目录（已被 .gitignore 排除）
- 贴吧抓取匿名调用公开接口，不涉及你的账号
